Client-Side Prototype Pollution

OWASP WASTG - Prototype Pollution ↗ CWE-1321 Improperly Controlled Modification of Object Prototype Attributes ↗

1. What is it?

Client-side prototype pollution is a JavaScript vulnerability where an attacker modifies an object's prototype (usually Object.prototype) through unsafe handling of user-controlled input.

2. Why it matters?

Prototype pollution allows attackers to manipulate inherited JavaScript object properties, potentially altering application behavior and bypassing security checks. It can lead to DOM-based XSS, unauthorized actions, or sensitive data exposure. In 2020, a vulnerability reported on HackerOne demonstrated how prototype pollution could be exploited to achieve XSS, allowing attackers to execute malicious JavaScript in a user's browser.
