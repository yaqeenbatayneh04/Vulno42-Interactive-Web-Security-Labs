# Vulno42 – Interactive Web Security Labs

## About the Project

Vulno42 is an interactive cybersecurity web platform developed as a final project for the **42 Advanced Digital Skills Program – Cybersecurity Track**.

The platform provides a hands-on learning experience where users can explore common web security vulnerabilities, understand how they work, simulate attacks, and learn how to fix them.

## Project Objectives

- Learn about common web security vulnerabilities.
- Understand how different attacks work.
- Explore vulnerable code and identify security weaknesses.
- Practice testing attacks and applying security fixes.

## Security Labs

The project includes three interactive web security labs with different difficulty levels.

### 1. DOM-Based Open Redirect (Easy)

This vulnerability occurs when JavaScript uses untrusted URL parameters to redirect users to external websites. Attackers can exploit it to redirect users to malicious websites.

### 2. Regular Expression Denial of Service (ReDoS) (Medium)

This vulnerability happens when a poorly designed regular expression takes too much time to process certain inputs. Attackers can exploit it to slow down or freeze the application.

### 3. Client-Side Prototype Pollution (Hard)

This vulnerability occurs when attackers inject malicious properties into JavaScript object prototypes. This can change application behavior and potentially lead to security issues.
