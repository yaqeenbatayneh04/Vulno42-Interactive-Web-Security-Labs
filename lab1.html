DOM-Based Open Redirect

OWASP A01:2021 — Broken Access Control ↗ CWE-601 — URL Redirection to Untrusted Site ↗

1. What is it?

DOM-Based Open Redirect is a client-side vulnerability that occurs when JavaScript uses an untrusted URL parameter to redirect users without proper validation. Attackers can exploit this behavior to send users from a trusted website to a malicious destination.

2. Why it matters?

Attackers can abuse trusted website links to redirect users to phishing pages, making malicious URLs appear legitimate. In 2014, a security issue known as Covert Redirect highlighted how unsafe redirect handling in OAuth authentication flows could expose users to phishing and unauthorized access risks.
